# Tiny Worlds ASMR Studio 1.2.0-draft

A reusable, model-agnostic prompt-production skill inspired by a public Cocojuan ASMR cooking tutorial and expanded for Hal Cooks, tiny-scale construction, edible illusions, and character-canon workflows.

## Use
Place this folder in an agent's supported skill directory, or attach `SKILL.md` to a chat and instruct the agent to follow it. Folder includes scene templates, reference bible and a fully scripted miniature-cabin example. Installation location/activation vary by product; the ZIP is portable, not proof of installation.

## What is original vs reconstructed
Reconstructed: choose theme, choose food, define ingredient order, choose tabletop, generate assembly and eating scenes. Original enhancements: scene C, physical-material rules, frame ledger, prompt QA, Hal/Ned/Kitt canon, credit conservation, sound design, loop endings.

The exact text of source tutorial 'Prompt 3' has NOT been independently verified. Do not claim to have recovered it.

Source: https://cocojuan.com/how-to-make-cooking-eating/

## Notes / decisions
`SKILL.md` includes **Production notes: choosing hands and arms**, with the Hal-vs-human rationale, per-scene Hands Mode settings (`HAL_CANON`, `HUMAN`, `NO_HANDS`), and a pre-generation anatomy QA procedure.
