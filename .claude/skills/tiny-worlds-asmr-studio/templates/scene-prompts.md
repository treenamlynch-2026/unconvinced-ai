# Copy-ready production prompt templates

## A. Precision assembly
Hyper-realistic [9:16] macro ASMR video. START FRAME: use [exact reference frame] unchanged as the opening shot. A [materials and exact dimensions] [hero object] sits on [surface] against [fixed backdrop]. [Character hand description, count and precise fingers OR two human black-gloved hands] performs ONLY these actions: [0–2s], [2–4s], [4–6s], [6–8s]. Keep a fixed physical camera, 85mm-macro photographic look, stable studio lighting, shallow but sufficient focus for the assembly. Each part makes physical contact with its correct destination; emit synchronous [sound list]. Finish at [specific exit-frame geometry] and hold [duration]. No other objects enter. NEGATIVE: extra hands/fingers, object substitution, floating pieces, disjointed tools, scene cuts, camera movement, material drift, text, logo, music.

## B. Eating / interaction (EDIBLE OBJECTS ONLY)
Start directly from [Scene A finished reference frame]. The same [fully described food, count of layers, toppings, size] stays on the same [plate] under the same [lighting/background]. [Verified character identity] lifts the food with [correct hand/anatomy]. [Time-coded one or two bite actions]. Each real bite removes a plausible amount from THIS EXACT item, leaving accumulating irregular bite marks without resetting. Include synchronized contact, crunch, soft chewing as warranted; maintain character expression and anatomy. [Camera fixed or one gentle track, choose ONE]. End at [exact frame]. NEGATIVE: replacement sandwich, fresh unbitten reset, extra fingers, unearned camera cuts, lips/voice mismatch, levitating food, nonfood swallowing, captions, watermark.

## C. Original optional payoff / loop closer (NOT recovered source Prompt 3)

Audio: [specific tactile final sound plus clean decay]. NEGATIVE: new props, wardrobe shifts, spontaneous extra characters, abrupt music, caption text, unexplained object reset.
