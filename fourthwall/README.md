# Fourthwall storefront theme

The **Coloring Books Refresh** theme went live on [shop.unconvinced.ai](https://shop.unconvinced.ai/) on November 24, 2026. Storefront deployment and product configuration are managed by Fourthwall. This directory records the customizations outside the portfolio application.

| File | Fourthwall location |
| --- | --- |
| `listing-header.html` | Style → Edit HTML code → Header code |
| `featured-collection.css` | Home → Featured collection → Advanced → Custom CSS |
| `asset-gallery.css` | Home → Gallery → Advanced → Custom CSS |
| `covers/` | Four uploaded front-and-back product mockups |

The homepage uses the **Disappearing Colors** banner and a black background. Set the featured section to the Coloring Books collection in the grid layout. The custom CSS shows Christmas Gnomes, Hal’s Cowboy Christmas, Hal’s Baby Animals, and Hal’s Farm Life in that order.

The cover mockups are referenced by a hidden homepage gallery and served by Fourthwall. Keep the gallery when editing the theme. If the artwork is uploaded again, update the corresponding image URLs in both the homepage CSS and header code. The header styles carry the same artwork through to the collection and product pages.

The repository snapshot covers the custom styles and listing mockups. The banner, product downloads, catalog settings, checkout, and payouts are managed in Fourthwall.
